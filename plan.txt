Modified Abstract
Heuristic Elevator Fleet Dispatcher Using A* State-Space Search
Most elevator systems still rely on first-come-first-served logic, which works well when traffic is light but can become inefficient during peak hours, when passengers may experience longer waiting times and unnecessary elevator movement. This project models elevator dispatching as a state-space search problem using the A* algorithm. Whenever a passenger request arrives, the system evaluates possible elevator assignments and searches for a suitable route based on the current elevator positions, passenger requests, travel cost, and capacity constraints.
The core of the system is the A* evaluation function, f(n) = g(n) + h(n), where g(n) represents the cost accumulated so far and h(n) estimates the remaining cost to reach the desired state. This allows the dispatcher to consider both the current movement cost and the estimated future cost instead of simply selecting the nearest elevator. A hard capacity constraint is also enforced, so an elevator that reaches its passenger limit cannot accept additional passengers.
To make the decision-making process transparent, the system provides a live visual interface showing elevator movements, floor queues, passenger requests, and the selected A* path. A console log can also display the search decisions and cost values behind each assignment, making the algorithm easier to observe and explain.
Overall, the project demonstrates how A* state-space search with capacity constraints can be applied to elevator fleet dispatching to reduce unnecessary movement and improve passenger service during changing traffic conditions.
